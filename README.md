## What is this?

A community-driven **health scoreboard** for open-source repos. Each badge shows:

- **Score /100** — How healthy is this repo? (license, docs, activity, issues, etc.)
- **Grade** (A–D) — At-a-glance quality rating
- **Click to see full report** — Detailed breakdown with contributors, languages, activity

The score is calculated by [GitScope](https://gitscope-micro.vercel.app) — a free, open-source repo analyzer.

## 🔍 How the Score Works

Each repo is scored /100 based on:

| Factor | Points | Why |
|--------|--------|-----|
| ✅ License | 20 | Clear licensing = trust |
| 📝 Description | 15 | Tells you what it is |
| 🏷️ Topics | 15 | Discoverability |
| ⭐ Stars >100 | 10 | Community signal |
| ⭐ Stars >1k | 10 | Scale signal |
| 🌿 Default branch | 10 | `main`/`master` = modern |
| 🐛 Low issues | 10 | <10 open issues |
| ⏱️ Recent push | 10 | Active in last 30 days |

**Total: 100** — Higher is healthier.
